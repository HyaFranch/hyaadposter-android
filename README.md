## About

**HyaAdPoster** is an Android app that helps automate Rolimons trade ads. It runs in the background and posts ads automatically on a schedule, even when the app is minimized.

## Features

* **Background service**
  Uses an Android Foreground Service to keep the bot running with the screen off or app closed.

* **Multiple accounts**
  Add multiple Roblox accounts and manage each account separately.

* **Trade profiles**
  Create different profiles with their own trade queues and settings.

* **Custom ad tags**
  Choose which Rolimons tags to use when posting ads:
  Any, Demand, Rares, RAP, Wishlist, Robux, Upgrade, Downgrade, Adds, and Projecteds.

* **Discord webhook support**
  Receive notifications when ads are posted or when something goes wrong.

* **Auto updates**
  The app checks for new versions and can update directly from the app.

* **Activity logs**
  View live bot activity and errors from the Logs tab.

## Setup

1. Install `app-release.apk` on your Android device.

   * Enable **Install unknown apps** if required.

2. Open HyaAdPoster and go to:
   **Accounts → Add Account**

3. Add your Roblox account using your Rolimons cookie.

4. Go to:
   **Profiles → Create Profile**

   Add the trades you want to advertise.

5. Open:
   **Settings → Background & Battery**

   Disable battery optimization so Android does not stop the bot.

6. Return to the Dashboard, select a profile, and press **Start Bot**.

7. You can minimize the app. The bot will continue running through the background service.
